GROK API SETUP

1. Open .env in the SCRAMBLE folder.
2. Set XAI_API_KEY=your_grok_api_key (starts with grok-).
3. Leave XAI_MODEL=grok-4.7 or change to another xAI model available to your account.
4. Run START-TUNNEL.bat. The launcher installs pypdf automatically.
5. Host selects TRIVIA (topic) or STUDY (lecture PDF), difficulty, and question count.
6. Generation status appears in the host question bank card.

API requests go to https://api.x.ai/v1/responses. The key stays in .env server-side; never paste it into a browser or commit .env to git. For Render use the service environment variable XAI_API_KEY.

Study mode reads text from PDF pages locally; scanned/image-only PDFs require OCR and cannot be used directly. PDF limit: 8 MB. To manage prompt size, the first 100,000 extracted characters are used.

Every batch is checked for the four-answer structure and correct-answer index; no extra validation/retry calls are made. Failed generation keeps the previous bank. API usage may incur charges.
