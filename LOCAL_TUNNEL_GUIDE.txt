SCRAMBLE - Windows local HTTPS tunnel testing

1. Unzip the entire archive (do not run START-TUNNEL from inside ZIP).
2. Double-click START-TUNNEL.bat on your Windows computer.
3. The first run creates a Python .venv and installs dependencies.
4. Install cloudflared if requested. You can also put cloudflared.exe next to START-TUNNEL.bat.
5. Wait for the displayed HTTPS tunnel URL. If tunnel creation fails, the launcher now reports it instead of silently using HTTP.
6. The browser opens http://localhost:8000. Click HOST GAME to create a room, then scan its QR code on your phone. Its QR address points to the public HTTPS tunnel.
7. Keep the launcher terminal open for the whole test. Close it / Ctrl+C to stop.

Local-only alternative: START.bat opens http://localhost:8000 without HTTPS. iPhone motion sensors generally require HTTPS.
The public tunnel URL is temporary and changes on restart; don't use it as a permanent deployed domain.
Do not share the tunnel URL publicly unless you intend to allow internet visitors into the game.

Only launch.py and the Windows launcher branding / cloudflared setup were changed for local testing; original UI assets are unchanged.
